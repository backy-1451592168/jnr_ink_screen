# DayIJoy 心选日 · 墨屏相框使用说明

7.3 寸六色墨水屏相框：用微信小程序推送纪念日画面，也可局域网临时传图。

---

## 三颗按键

| 按键 | 怎么用 |
| --- | --- |
| **模式键** | 双击：绿灯（小程序推送）↔ 青灯（局域网传图）。单击无效 |
| **执行键** | 未绑定：短按查绑定。已绑定：长按约 2 秒拉最新画面；双击本地再刷当前图 |
| **系统键** | 按住约 3 秒后**松手**：重配 WiFi。按住约 8 秒：出厂重置 |

---

## 指示灯

| 灯色 | 含义 |
| --- | --- |
| 绿灯常亮 | 小程序推送模式（日常） |
| 青灯常亮 | 局域网传图模式 |
| 黄灯闪 | 正在连家里 WiFi / 断网重连 |
| 橙灯闪 | 配网中（热点已开） |
| 紫灯呼吸 | 下载或刷屏中 |
| 红灯闪几下 | 失败（多为网络），稍后再试 |

**按住系统键时**：橙常亮（未满 3 秒）→ 黄慢闪（松手即重配）→ 红快闪（将出厂）。

全刷约 **15～20 秒**，可能闪白、反色，属正常。刷完灯会回到绿/青。

---

## 第一次使用

### 1. 配网

1. 通电。首次或无 WiFi 时橙灯闪，开热点 `DayIJoy-心选日`（无密码）。
2. 手机连该热点，打开配网页（一般会自动弹出，或访问 `http://192.168.8.1/`）。
3. 点选或**手动输入**家里 WiFi 名称，填密码，保存连接。
4. 按提示把手机切回家里 WiFi；可先复制管理页地址。
5. 打开管理页，确认服务地址后点「完成并重启」。

以后换 WiFi：系统键按住约 3 秒松手，再按上面步骤（不解绑）。

### 2. 小程序绑定

1. 配网成功后，屏上出现绑定二维码。
2. 小程序 → **墨屏相框** → **扫码绑定**。
3. 设置竖/横屏与展示的纪念日并保存。
4. 短按执行键，相框会立刻检查并拉画面。

一个微信账号绑定一台相框。未绑定期间约每 60 秒自动再查一次。

## 日常使用

**小程序**

- 看在线/同步状态；「相框设置」可改竖横屏、展示规则。
- 改完保存；要马上出新图：小程序可点「立即重新渲染」，相框再**长按执行键约 2 秒**拉取。

**相框（绿灯）**

- 长按执行键约 2 秒：从网上拉最新画面。
- 双击执行键：本地再刷当前图（消残影）。
- 下载中再按执行键可取消；**全刷开始后无法中断**（灯会黄闪确认已按到）。
- 也可等每天自动同步（默认约午夜，可在管理页改）。

**还在显示二维码时**：短按执行键再查绑定；此时模式键无效。

## 局域网传图（可选）

1. 双击模式键 → 青灯。
2. 长按执行键约 2 秒 → 屏上出现 `http://相框IP/upload`。
3. 手机与相框同一 WiFi，浏览器打开该地址，选方向、上传图片。
4. 页面会提示刷屏进度，约 15～20 秒完成。
5. 再长按执行键可退出地址页。

这是临时图，不改小程序正式画面。双击模式键回绿灯后，长按执行键可再拉正式纪念日画面。青灯停留约 10 分钟会灯闪提醒切回。

## 换绑与出厂

**换绑**

1. 小程序「相框设置」→「解除绑定」。
2. 相框长按执行键（或稍等），重新出现二维码。
3. 再扫码绑定。

**出厂（系统键约 8 秒）**

- 屏上会提示「请先小程序解绑」，再清本地 WiFi/绑定/缓存并重启。
- 只清设备本地；云端仍绑着时，请先在小程序解绑再扫码。
- 仅重配 WiFi（约 3 秒松手）**不会**解绑。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 小程序改了，屏没变 | 确认绿灯、能上网；长按执行键约 2 秒；小程序刷新状态 |
| 一直停在二维码 | 确认已扫码并保存设置；短按执行键再查；检查 WiFi |
| 红灯闪 | 多半暂时没网；检查路由，或系统键约 3 秒重配 |
| 家里 WiFi 改密码后一直黄闪 | 会自动重连；约 5 分钟仍失败会清 WiFi 并重新进入配网 |
| 刷屏很久像坏了 | 全刷约 15～20 秒，灯回绿/青即正常 |
| 断电画面还在吗 | 在。墨水屏断电也保持最后一张 |

---

## 小贴士

- 干燥通风放置，避免强光长时间直射。
- 不必频繁刷屏；有更新再拉即可。
- 日常保持绿灯；误切到青灯时双击模式键切回。
